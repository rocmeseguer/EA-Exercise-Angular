# EaExerciseAngular

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 16.2.16 and updated to **Angular 21**.

The Angular CLI is installed **locally** in this project.

## Requirements

Node.js `^20.19.0 || ^22.12.0 || >=24.0.0`

## Installation

Install dependencies (the Angular CLI is a dev dependency)

```
npm install
```

## Development server

Run `npx ng serve` (or `npm start`) for a dev server and open `http://localhost:4200/`.

## Code scaffolding

Run `npx ng generate component component-name` to generate a new component.

## Tests

Run `npx ng test` to execute the unit tests with [Vitest](https://vitest.dev/).
